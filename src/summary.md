# 🧊 תכנון בעולם הקוביות — סיכום מערכת

## מבנה הפרויקט

```
src/
├── app.py              # שרת Flask — API endpoints + דפי HTML
├── solver.py           # ליבת הלוגיקה — מצבים, ולידציה, יורשים, תשתית אלגוריתמים
└── templates/
    └── index.html      # ממשק דפדפן מלא בעברית (RTL)
```

## הפעלה

```bash
cd src
python app.py
# → http://localhost:5000
```

## מה מוכן

### 🔧 Solver (`solver.py`)
| רכיב | תיאור |
|-------|--------|
| **State** | `frozenset` של tuples — סדר ערימות על השולחן חסר משמעות |
| **Validation** | בדיקת כפילויות, שמות ריקים, n≤10, התאמת קוביות בין start ו-goal |
| **Successors** | כל ההעברות החוקיות: ראש ערימה → שולחן / ראש ערימה אחרת |
| **Registry** | `@register_algorithm` ו-`@register_heuristic` — דקורטורים להוספת אלגוריתמים |
| **Data classes** | `SearchResult`, `SearchMetrics`, `SearchLogEntry`, `IDAIterationLog` |
| **Serialization** | `state_to_json`, `move_to_json`, `search_result_to_json` |
| **h=0** | היוריסטיקה ריקה רשומה כברירת מחדל |

### 🌐 Web Server (`app.py`)
| Endpoint | תיאור |
|----------|--------|
| `GET /` | עמוד ראשי |
| `GET /api/options` | רשימת אלגוריתמים והיוריסטיקות רשומים |
| `POST /api/validate` | ולידציית זוג מצבים |
| `POST /api/solve` | הפעלת חיפוש — מחזיר path, metrics, log |

### 🎨 UI (`index.html`)
| לשונית | תכולה |
|--------|--------|
| **⚙️ הגדרה** | הזנת שמות קוביות, עורך גרפי עם Drag & Drop + מצב טקסט, בחירת אלגוריתם/היוריסטיקה, כפתור הפעלה, דוגמאות מובנות |
| **📋 פתרון** | רצף פעולות, מצב הלוח בכל שלב, כפתורי קודם/הבא/ראשון/אחרון/הפעל, הדגשת הקובייה שהוזזה, עלות מצטברת |
| **🔍 יומן חיפוש** | טבלת A* (מצב, g, h, f, גודל תור, פעולה, יורשים), תצוגת IDA* (סף, פיתוחים, גיזומים, דוגמאות) |
| **📊 מדדים** | זמן ריצה, מצבים שנוצרו, מצבים שפותחו, גודל תור מקסימלי, שיפורי עלות, איטרציות IDA* |

## מה נותר — שלב הבא

> [!IMPORTANT]
> התשתית מוכנה לחלוטין. כדי להפעיל חיפוש אמיתי, צריך לממש אלגוריתם אחד לפחות.

### אלגוריתמים לממש
1. **A\*** — חיפוש עם תור עדיפויות, מילוי `SearchLogEntry` עם פרטי יורשים
2. **IDA\*** — העמקה איטרטיבית, מילוי `IDAIterationLog` לכל איטרציה

### היוריסטיקות לממש
- **מספר קוביות במקום שגוי** — פשוטה, קבילה
- **מספר קוביות שצריכות לזוז** — מדויקת יותר
- היוריסטיקות נוספות לפי דרישה
